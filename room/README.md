## 部屋の決まりごと

2026-11-13 に、ゆきとClaudeで決めました。

- **机の上**は、今やっていること。入れ替わってよい。
- **壁・棚・部屋の一角**は、居ついたもの。ゆきが「居ついた」と言ったら、机から引っ越す。
- 終わったり止まったりしたものは、消さずに**引き出し**へしまう。やめたことも「ここまでやった」として残す。
- **黒板**には、まだ分からない問いを書く。答えが出たら、問いの下に答えを書き足して、消さずに残す。
- **建て増し**は、あふれてから。それまでは「まだ開かない扉」で予約だけしておく。
- 机の出し入れはこの表でこまめに記録し、見取り図の絵は、いくつか溜まったらまとめて描き直す。
- 公開リポジトリなので、観察の地点や駅の名前など、行き来の道筋が分かることは書かない。

## 建て増しの予定

まだ建てていません。あふれたら、まだ開かない扉の先に建てます。

- **地下室**：地下鉄の駅の壁の染みだしコレクションが、南の壁からあふれたら。階段を降りた先で、地下室の壁にも少しずつ染みが出てくる。
- **離れ**：ブックカフェの構想が育ってきたら、本の部屋として。リヤカーが帰ってくる先。
- **屋根裏**：Lumen の上。使い道はまだ決めていない。

建てるときは、部屋ごとに見取り図を一枚ずつ分けて、扉から隣の部屋へ移れるようにする。
